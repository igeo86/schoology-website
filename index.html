Schoology Downloader

A personal tool that copies authorized school course attachments to the account owner’s Google Drive, organized by subject and course folder.

How it works

The downloader runs on the owner’s Raspberry Pi. It reads course materials using the owner’s Schoology session, saves attachments locally, and uses rclone to upload them to a dedicated Google Drive folder.

Google authorization uses the drive.file permission, allowing the integration to access files and folders it creates or that are specifically authorized to it. The tool is for personal use and does not provide a public sign-up service.

This informational website does not host school files or request account passwords.
